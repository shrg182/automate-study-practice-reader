Draft library

2026-09-01 · Exported a new article. It seems that it has the same process as the diary which it is not listed in the article list after closing it.

Corrected. Reader Articles Studio now has a browser-local “Draft library.”

After refreshing the Studio:

  1. Click “Draft library.”
  2. The previously active article should migrate automatically.
  3. If it is absent because another draft replaced it, use “Import backup” and select the exported JSON.
  4. It will then remain listed alongside future drafts.

The Draft library is private and browser-local. The Reader catalog remains reserved for deliberately published articles.
