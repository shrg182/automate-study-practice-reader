For authentication, I recommend Flask-Login + Werkzeug password hashing + SQLite/SQLAlchemy. Passwords would never be stored directly; registration would store only a hashed password, and Flask sessions would keep the user logged in securely.

The first usable version should include these features:

  1. Register account.

  2. Log in and log out.

  3. Protect pages so unauthenticated users cannot access the library.

  4. Give every user a separate personal library.

  5. Upload/import .txt and .md books.

  6. Read books in the browser.

  7. Save reading position.

  8. Add bookmarks and notes.

  9. Save vocabulary while reading.

  10. Search the user's own books and vocabulary.
