Implemented safe personal-backup restoration.

New restoration workflow:

  1. Upload a Reader backup ZIP.
  2. Validate its archive, manifest, SQLite integrity, and schema.
  3. Preview books, annotations, vocabulary, and duplicate conflicts.
  4. Explicitly confirm restoration.
  5. Restore everything into the current account with newly assigned IDs.

Safety guarantees:

  • Archive traversal and expansion limits
  • 100 MB upload limit
  • Read-only inspection of the backup database
  • Content-hash verification
  • Duplicate books skipped
  • Passwords and original account identity never restored
  • EPUB chapters and assets regenerated safely
  • Transactional database restoration
  • Newly created files removed if restoration fails
  • Abandoned uploads removed after 24 hours
  • Restore tokens bound to the current session and account
  • Existing reader preferences preserved
