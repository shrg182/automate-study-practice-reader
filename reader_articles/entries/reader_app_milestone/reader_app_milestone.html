The next milestone should make the reader useful for active study: annotations, highlights, and vocabulary.

Recommended order:

  1. Stable text anchoring
    Give each paragraph and text segment a durable identifier so highlights survive reopening, resizing, and font changes.

  2. Highlights and notes
    Select text, choose a highlight color, attach a note, edit/delete annotations, and show them again inside the book.

  3. Vocabulary collection
    Select a word or phrase and save it with language, definition, context sentence, source book, and optional personal note.

  4. Notes and vocabulary dashboards
    Search/filter saved items by book, language, date, or keyword; jump from an item back to its original passage.

  5. Reader controls
    Font family, font size, line spacing, reading width, light/sepia/dark themes, and a collapsible sidebar.

  6. Import improvements
    Chapter detection for TXT/Markdown, duplicate-file detection, metadata editing, and safe book deletion.

After those foundations are stable:

  • EPUB support
  • PDF support
  • Dictionaries and multilingual lookup
  • Export/backup
  • Database migrations and production deployment

The immediate implementation target I recommend is: durable text anchors plus complete highlight/note support, including ownership tests and restoration after reopening a book.

Next should be library management, backup, and export before introducing EPUB.

Recommended milestone:

  1. Book management

  3. Data export

    • Export vocabulary as CSV
    • Export notes and highlights as Markdown
    • Export a single book’s study material

  4. Personal backup

    • Download a ZIP containing the database, uploaded books, and a manifest
    • Provide clear restoration instructions

    • Transactional database cleanup
    • Remove the stored file only after confirming no remaining record uses it
    • Tests for ownership and failure recovery

Next is EPUB support, which should be implemented as a chapter-aware reading format rather than flattened into one large text file.

Recommended milestone:

  1. Safe EPUB import

    • Validate the ZIP structure and required EPUB files
    • Reject encrypted, malformed, or oversized archives
    • Extract metadata: title, author, language, identifier, and cover
    • Continue using SHA-256 duplicate detection
    • Prevent archive path traversal

  2. EPUB processing

    • Parse the package manifest and reading order
    • Sanitize chapter XHTML
    • Rewrite internal chapter links
    • Extract images and styles safely
    • Store a normalized chapter representation

  3. Chapter-based reader

    • Navigate between chapters
    • Generate the table of contents from EPUB navigation metadata
    • Remember chapter plus within-chapter position
    • Support responsive images and footnotes
    • Preserve appearance controls

  4. EPUB annotations

    • Store anchors as chapter identifier plus character offsets
    • Restore highlights and vocabulary within the correct chapter
    • Make dashboard source links open the correct chapter

  5. Migration and compatibility

    • Add format-specific location fields without breaking TXT/Markdown records
    • Keep current progress and annotations working unchanged
    • Add malformed-file, ownership, Unicode, navigation, and anchoring tests

After EPUB is stable, the next steps should be restoration from personal backups, then PDF support.
