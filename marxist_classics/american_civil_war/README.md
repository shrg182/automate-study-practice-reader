# 马克思、恩格斯论美国内战

本目录收录中文马克思主义文库“论美国内战”专题的 113 篇论文、通信和附录目录。它属于“马克思主义经典”，并与 `practice/american_civil_war` 的战役年表互相链接，但不混合两类资料。

## 更新目录

源页面使用 GB2312 编码；下载后可用兼容的 GB18030 解码：

```bash
python3 practice/marxist_classics/american_civil_war/manage.py --source-file /path/to/us-civilwar.htm
```

打开 `select_readings.html` 可搜索、筛选、选择条目，并在每篇文章旁撰写按语或帖子。按语按文章序号自动保存在浏览器的本地存储中，选择条目导出处理清单时也会写入对应条目的 `commentary` 字段。完整正文按选择结果另行获取，不在目录构建阶段批量镜像。
