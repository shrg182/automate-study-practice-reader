来源：[五千言《聂小倩》](https://liaozhai.5000yan.com/19985.html)

源网页在同一地址中提供“对照 / 原文 / 译文”三种显示方式。本目录的下载器直接选择 `data-section="原文"` 段落，只保存原文，不收录对照文本、现代汉语译文或点评。

初始网页文本包含三个缺字占位符；处理时先原样保留，待人工校读确认后再写回。

2026-08-10 已再次导入浏览器人工校读备份：正文格式、45 处注音、1 条行间注、4 条脚注、3 条按语及新增词条均已保留。人工查定的 `𪑦`、`㑌` 已写回清稿；网页仍未显示的“半年渐啜稀[生僻字]”继续列为待核。四张实际关联的图片保存在 `media/`，并已移入正文中相应段落的位置；导出中未关联的重复或已删除图片没有写入项目。

清稿文件只保留原文，不混入按语或脚注内容。编辑器的清稿视图隐藏按语、脚注标记和各注释汇总区；语音朗读会从独立的原文副本中排除注音、行间注、脚注和按语，即使切换到注音稿也只朗读原文。
