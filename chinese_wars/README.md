# 中国历代战争阅读清单

本目录把“战争列表”按《古文观止》的选择—处理—编辑器工作流接入校读书斋。现已覆盖从史前与夏朝至中华人民共和国时期的 21 个历史分期，共 1,697 项。

## 使用方式

1. 打开 `select_entries.html`，搜索或筛选战争条目。
2. 勾选需要阅读的条目，导出 `chinese_wars_processing_queue.json`。
3. 运行：

   ```bash
   python3 practice/chinese_wars/manage.py process ~/Downloads/chinese_wars_processing_queue.json
   ```

4. 所选条目会按历史时期合并进对应编辑器；首页也会同步更新。

## 编辑原则

- 保留来源中的原始年代写法，不擅自统一有争议的上古纪年。
- 保留“存疑”“不一定可信”等说明，并在选择器中显著标识。
- 文学城页面是本次任务入口；每一项尽可能链接到嵌入列表给出的维基百科或维基文库条目。
- 目录同时支持来源中的项目符号列表和“战役名称／年份”表格；处理后统一按历史时期生成编辑器。

## 数据来源

- [文学城：小常识：中国历代战争](https://bbs.wenxuecity.com/memory/1920809.html)
- [维基百科：中国战争列表](https://zh.wikipedia.org/wiki/中国战争列表)

本目录保存的是阅读工作流所需的条目、来源链接和编辑状态；它不是独立的历史事实校订成果。
