# Personal Writings Studio

This collection is for diaries, schedules, journals, reflections, reading notes,
and meeting notes. Its content remains in the current browser unless the reader
explicitly exports a JSON backup or prints a PDF.

The browser-local library retains multiple imported or newly created entries and
provides search and date-based switching without publishing their contents.
Existing single-draft browser data migrates into the library automatically.

The rich-text toolbar supports headings, emphasis, lists, links, four highlight
colors, footnotes, and inline images. Images are stored as data URLs inside the
portable backup. The optional `footnotes` field is backward-compatible with
earlier `personal-writing-v1` backups.

It is intentionally separate from publication-oriented `reader_articles/` and
the fixed reports in `news_reports/`.
