# 《史记·商君列传》阅读材料

本目录处理古文岛《七十列传·商君列传第八》，沿用
`practice/shiji/README.md` 的来源、清稿、词表、编辑器与 PDF 工作流。

## 来源与状态

- 正文：<https://www.guwendao.net/guwen/bookv_294ca85f5800.aspx>
- 篇名：七十列传·商君列传第八
- 提取方式：解析网页 `div.contson` 内的直接段落，无 OCR
- 初始规模：3,377 个字符，12 个自然段
- 当前清稿：3,955 个字符，含人工按语及 3 条脚注
- 当前输出：38 条阅读词典、注音文本、自包含校读编辑器和 7 页注音 PDF
- 当前状态：2026-08-02 已导入人工编辑备份、编辑日志和阅读札记，重新生成全部输出；PDF 首页、脚注页及阅读词表页已渲染检查

`source.txt` 保存网页原始提取结果，`shangjun_clean.txt` 是校订与生成依据。
网页底本中的缺字残码及疑似异文已登记在 `review_notes.tsv`，未擅自改入清稿。

校读编辑器支持选中文字后设置任意背景高亮色；更改颜色会立即应用，也可点击
“应用背景色”按钮（或在按钮上按 Enter）。粗体与带间距的下划线可独立或叠加
使用。样式随浏览器自动保存、JSON 备份和 HTML 导出一并保留；TXT 导出仍保持
纯文本。

“待核”登记项提供“标为完成”和“删除”两个独立操作。删除待核标记前会要求
确认，并只移除标记及其说明，保留正文文字。

脚注编辑框会在载入和输入时按内容自动增高，使较长的脚注完整显示，不再局限于
固定高度的内部滚动区域；仍可手动纵向调整高度。

编辑器备份中的背景高亮、粗体和下划线会导入 `text_styles.json`，并由注音 PDF
生成器恢复。当前备份含 5 项格式（2 项背景高亮、1 项粗体、2 项下划线）。PDF
使用真正的 Songti SC Bold 字体绘制粗体，下划线以 0.7 点线宽在基线下移 4 点
绘制；浏览器导出的 `rgb(...)` 背景色会自动转换为 PDF 可用的十六进制颜色。

## 生成

```bash
cd practice/shiji/shiji_shangjun
python3 download_article.py
python3 make_rare_word_table.py
python3 make_annotated_pdf.py --annotated-text-output shangjun_annotated.txt
python3 build_editor.py
```

开始人工校订后不要直接重跑下载脚本；脚本会更新网页快照和 `source.txt`，但只在
`shangjun_clean.txt` 尚不存在时建立初始清稿。

## 配额

本地下载、解析、词表匹配、编辑器和 PDF 生成不调用模型 API。若以模型复核全文，
按 3,377 个字符估算，建议为输入、结构化词表输出和第二轮复核共预留约
8,000–12,000 tokens。
