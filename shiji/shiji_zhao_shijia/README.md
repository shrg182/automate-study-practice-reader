## 生成

```bash
cd practice/shiji/shiji_zhao_shijia
python3 download_article.py
python3 make_rare_word_table.py
python3 make_annotated_pdf.py --annotated-text-output zhao_shijia_annotated.txt
python3 build_editor.py
```

打开 [`editor.html`](editor.html) 使用清稿、注音稿、脚注、行间注、按语、待核、用户札记和编辑日志工作流。
