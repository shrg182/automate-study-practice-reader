# 校读书房 · Mobile Reading Room

This public repository contains the installable reading site generated from the private `automate_study_practices` workspace.

Live site: <https://shrg182.github.io/automate-study-practice-reader/>

The site is intended for personal reading, proofreading, and educational study. It is not affiliated with the websites cited as source material; rights in the original material remain with their respective rights holders.

On a phone, open the live site and choose **Add to Home Screen** or **Install app**. Use the article-level `离线` button to retain selected articles for offline reading.
