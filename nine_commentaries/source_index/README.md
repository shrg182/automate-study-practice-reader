# 中苏论战与九评文献目录

本目录保存中文马克思主义文库“中苏论战资料”专题的 49 篇文献索引：中方文献、九评苏共中央公开信和苏方文献。

```bash
python3 practice/nine_commentaries/source_index/manage.py --source-file /path/to/index.htm
```

源页面使用 GB2312 编码，构建器以 GB18030 兼容解码并生成 UTF-8 CSV 和选择器。正文按选择结果另行处理。

来源：[中苏论战资料](https://www.marxists.org/chinese/reference-books/sino-soviet-debate/index.htm)
