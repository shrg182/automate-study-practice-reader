# 01
手太阴肺经

手太阴肺经是人体十二经脉之首，左右两侧共有22个穴位。 [1, 2]
## 基本概况

* 走向：从胸走手（起于中焦，终于大拇指端）
* 表里关系：与[手阳明大肠经](https://baike.baidu.com/item/%E6%89%8B%E5%A4%AA%E9%98%B4%E8%82%BA%E7%BB%8F/7077192)相表里
* 穴位数量：每侧11穴，双侧共22穴 [1, 2, 3]

## 循行路线

* 主干路线：起始于中焦胃部，向下联络大肠，回过来沿着胃上口，穿过膈肌，属于肺脏。从气管、喉咙部横出腋下，沿着上臂内侧前缘下行，经过肘窝、前臂内侧桡骨边缘，进入手腕桡动脉搏动处（寸口），走大鱼际边缘，出大拇指桡侧端（少商）。
* 分支：从腕后（列缺穴）分出，走向食指桡侧端，连接手阳明大肠经。 [2, 4, 5, 6]

## 属下十一穴位

   1. 中府 (LU1)
   2. 云门 (LU2)
   3. 天府 (LU3)
   4. 侠白 (LU4)
   5. 尺泽 (LU5)
   6. 孔最 (LU6)
   7. 列缺 (LU7)
   8. 经渠 (LU8)
   9. 太渊 (LU9)
   10. 鱼际 (LU10)
   11. 少商 (LU11) [7]

## 主要主治

* 呼吸系统：咳嗽、气喘、咯血、胸痛。
* 五官咽喉：咽喉肿痛、扁桃体炎、鼻炎。
* 其他：经脉循行部位的关节和肌肉酸痛。 [2, 8]

# 02
手阳明大肠经

手阳明大肠经是人体十二正经之一，左右两侧共有40个穴位。 [1]
## 基本概况

* 表里关系：与[手太阴肺经](https://baike.baidu.com/item/%E6%89%8B%E9%98%B3%E6%98%8E%E5%A4%A7%E8%82%A0%E7%BB%8F/7077565)相表里。
* 流注时间：卯时（清晨5点至7点），此时气血流注大肠经，最适合排便与排毒。
* 主治特点：主治头面、五官、咽喉病症，以及热病和经脉循行部位的病变。 [1, 2, 3]

## 经脉循行

* 起止点：起于食指桡侧端的商阳穴，沿着上肢外侧前缘上行，经肩部、颈部，最终到达鼻翼两侧的迎香穴。
* 体内联络：从缺盆（锁骨上窝）进入胸腔，络属于肺，向下穿过膈肌，属于大肠。 [4, 5]

## 常用核心穴位

* 合谷：第一、二掌骨间，常用于缓解头面痛、牙痛及感冒。
* 曲池：肘横纹外侧端，主治手臂痛、发热及皮肤病。
* 迎香：鼻翼外缘中点旁，主治鼻炎、鼻塞等鼻部疾患。
* 商阳：食指甲根角桡侧，常用于清热和急救。 [3]

# 03
足阳明胃经

足阳明胃经是人体十二经脉之一，多气多血，左右两侧共有90个穴位（单侧45穴）。 [1, 2]
## 经脉概况

* 流向与分布：循行方向自头走足，分布于面部、胸腹部正侧面及下肢外侧前沿。
* 起止穴位：首穴为承泣穴（眼眶下缘），末穴为厉兑穴（足次趾外侧端）。
* 主治范围：主治肠胃等消化系统、头面五官（咽喉、口、齿、鼻、面部）病症、神志病以及经脉循行部位的病变。 [1, 3, 4, 5, 6]

## 重点穴位与功效

* 足三里：位于犊鼻穴下3寸，为合穴与强壮保健要穴，主治胃肠道疾病及全身调理。
* 丰隆穴：位于外踝尖上8寸，是化痰常用穴位。
* 冲阳穴：足阳明胃经之原穴，原气留止之重要部位。
* 乳中穴：位于第四肋间隙，仅作定位标志，不针不灸。 [6, 7]

# 04
足太阴脾经

足太阴脾经是人体十二正经之一，左右两侧共有42个穴位（单侧21穴），与足阳明胃经相表里。 [1, 2]
## 循行路线

* 起于足部：从大脚趾末端（隐白穴）开始，沿内侧赤白肉际处上行。
* 经过小腿与大腿：经过内踝前廉、小腿内侧、内踝尖上八寸处交出足厥阴肝经之前，再沿大腿内侧前缘上行。
* 进入腹部与胸部：进入腹部，属于脾，络于胃；向上穿过膈肌，沿食管两旁，连舌本，散舌下。
* 分支：支脉从胃别出，上行通过膈肌注入心中。 [3]

## 常用穴位（共21穴）
隐白、大都、太白、公孙、商丘、三阴交、漏谷、地机、阴陵泉、血海、箕门、冲门、府舍、腹结、大横、腹哀、食窦、天溪、胸乡、周荣、大包。 [1]
## 主要功能与主治

* 消化系统：主治消化不良、腹胀、腹泻、便秘等脾胃病症。
* 妇科病症：常用于调理月经不调、痛经等（如三阴交、血海等穴）。
* 运化水湿：有助于改善身体水肿、困倦乏力等气血不足症状。 [4]

手少阴心经

手少阴心经是人体十二经脉之一，属于手三阴经之一，与手太阳小肠经相表里。 [1]
该经脉左右两侧各有9个穴位（共18穴），首穴是极泉，末穴是少冲。 [2, 3]
------------------------------
## 1. 穴位分布（穴位歌诀）
手少阴心经的9个穴位依次为： [3, 4]

* 极泉（腋窝正中）
* 青灵
* 少海（肘内侧）
* 灵道
* 通里
* 阴郄
* 神门
* 少府
* 少冲（小指桡侧端） [3, 5, 6]

------------------------------
## 2. 经脉循行

* 起于心中，向下联络小肠。
* 分支：从心系向上挟着咽喉，连结眼睛的系带。
* 主干：向上到达肺部，再向下出于腋窝（极泉），沿着手臂内侧后缘，经过肘内侧，下行到手掌内侧，到达小指的末端（少冲）。 [1, 3]

------------------------------
## 3. 主治病症
手少阴心经主要治疗心、胸、神志方面的疾病，以及经脉循行部位的病症。常见症状包括： [1]

* 心系病症：心痛、心烦、惊悸、失眠健忘。
* 胸部与循行部位病症：胸闷、咽干、口渴、胁痛，以及上肢内侧后缘疼痛、手掌发热等。 [1, 7]

# 06
手太阳小肠经

手太阳小肠经是中医十二正经之一，左右两侧共有38个穴位（单侧19穴），起于小指末端的少泽穴，止于耳中的听宫穴。 [1, 2]
## 基本概况

* 循行方向：从手走头。
* 表里关系：与手少阴心经相表里。
* 起止穴位：起点为少泽，终点为听宫。 [2, 3]

## 循行路径

   1. 体表路线：从小指外侧端（少泽）起，沿手掌外侧、手腕、前臂后缘、肘关节内侧、上臂外侧后缘，到达肩关节和肩胛部，交会于大椎穴，再向前进入锁骨上窝（缺盆）。
   2. 体内联系：从缺盆深入体内，络于心，沿着食道下行通过膈肌，到达胃，属于小肠。
   3. 头部分支：缺盆分出的支脉沿颈部、面颊到达眼外角（目锐眦），进入耳中（听宫）；另一支脉从面颊分出，抵达鼻根、眼内角（接足太阳膀胱经）。 [3, 4, 5]

## 包含穴位（单侧19穴）
少泽、前谷、后溪、腕骨、阳谷、养老、支正、小海、肩贞、臑俞、天宗、秉风、曲垣、肩外俞、肩中俞、天窗、天容、颧髎、听宫。 [3]
## 主治概要
主要治疗头项、耳、目、咽喉病变，以及热病和经脉循行部位的疼痛（如肩背痛、肘臂痛等）。 [6]

# 07
足太阳膀胱经

足太阳膀胱经是人体十二经脉中穴位最多、循行路线最长的经脉，左右两侧共有134个穴位（单侧67穴）。 [1, 2]
## 基本概况

* 表里关系：与足少阴肾经相表里。
* 流注时间：申时（下午15点至17点）气血最旺。
* 穴位总数：单侧67穴（头面与腰背部49穴，下肢后侧18穴）。 [3, 4]

## 循行路线

* 起点与走向：起于内眼角的[睛明穴](https://baike.baidu.com/item/%E8%B6%B3%E5%A4%AA%E9%98%B3%E8%86%80%E8%83%B1%E7%BB%8F/1225387)，上行至额部与巅顶。
* 背部循行：从巅顶向下进入颅内联络脑，分出后行于项部，沿脊柱两侧（旁开1.5寸和3寸）向下到达腰、臀部，进入后侧大腿至腘窝。
* 终点：穿过小腿腓肠肌，经外踝后方至足小趾外侧端的至阴穴，交于足少阴肾经。 [1, 5]

## 主要功能与主治

* 生理功能：调节水液代谢、主一身之表及腰背功能。
* 主治范围：头面、眼目、项背、腰腿痛等病症，以及神志疾患和内脏功能失调。如需了解详细内容，可参考足太阳膀胱经百科。 [1, 6]

# 08
足少阴肾经

足少阴肾经是人体十二经脉之一，简称肾经，左右两侧共有54穴（单侧27穴）。 [1, 2]
## 经脉循行

* 起止：起于足小趾下，斜走足心（[涌泉穴](https://baike.baidu.com/item/%E8%B6%B3%E5%B0%91%E9%98%B4%E8%82%BE%E7%BB%8F/1708893)），沿内踝后方上行，贯脊属于肾，络于膀胱。
* 体内分支：直行支脉从肾上通肝膈、进入肺中、循喉咙、挟舌本；另一支脉从肺出，络心，注胸中。

带脉

带脉是中医奇经八脉中唯一一条横向环绕腰腹部的经脉，主要功能是“约束诸经”和调节全身气血。 [1, 2]
## 什么是带脉？

* 位置：在大致与肚脐平行的腰腹两侧，就像系腰带一样环绕身体一周。核心穴位可参考[带脉穴](https://baike.baidu.com/item/%E5%B8%A6%E8%84%89%E7%A9%B4/462019)。
* 作用：统束纵向的经脉，连结上下气血，对腰腹、妇科及内脏有保护和固摄作用。
* 不通的表现：久坐或寒湿可能导致带脉不畅，容易引起腰腹僵硬、小腹赘肉或月经不调。 [1, 2, 3, 4, 5, 6, 7]

## 在家调理带脉的方法
可参考[家庭医生在线](https://www.familydoctor.cn/hlthsci/zaijia-shutong-daimai-zhongfangfa-bi-keng-zhinan-chashou-700953.html)的科学建议进行日常养护：

* 按摩：用手掌根部在腰腹两侧环形揉按，每次10到15分钟，力度以酸胀舒适为宜。
* 轻敲：双手握空拳，沿着带脉轻轻敲打100到200下，使皮肤微微发热。
* 艾灸：对准带脉穴进行温和灸，每次15到20分钟，能温通经络。 [5]

## 注意事项

* 力度适中：敲打和按摩不要过度用力，以免损伤软组织。
* 人群禁忌：孕妇或腰腹有伤口的人不宜进行敲打和艾灸。
* 理性看待：带脉疏通属于日常养生辅助，不能替代正规医疗或科学减肥。 [5]

# 17
阴跷脉

阴跷脉是中医学中奇经八脉之一，具有调节下肢运动和眼睑开合、控制睡眠的重要作用。 [1, 2]
## 1. 循行路径

* 起止与经过：起于足跟内侧足少阴肾经的照海穴，上行经过内踝、大腿内侧、前阴、腹面、胸部、缺盆、人迎穴前、喉结旁、鼻旁，最后连属于眼内角，并会合足太阳经及阳跷脉。
* 交会穴：左右两侧共6穴，包括照海、交信、睛明。 [1]

## 2. 生理功能

* 司下肢运动：主一身之阴，调节下肢肌肉，使双腿活动灵活、矫捷，维持下肢正常步态与平衡。
* 司眼睑开合与睡眠：循行上达目内眦，与阳跷脉共同调节眼睑的开合。阴跷脉主阴气，阴跷脉盛时容易使人眼睑闭合而入睡。 [1, 2, 3, 4]

## 3. 病候表现

* 运动障碍：若阴跷脉失养或异常，常见足内翻、下肢肌肉萎缩（腿腹肌削）、痿痹无力或行走不稳。
* 睡眠与眼睑异常：可导致嗜睡（阴气盛）或失眠，以及眼睑下垂等症。 [1, 4]

# 18
阳跷脉

阳跷脉是中医学“奇经八脉”之一，主要负责调节全身阳气、支配下肢运动以及控制眼睛开合。 [1, 2, 3]
## 主要循行路线

* 起于足跟：起于足跟外侧的[申脉穴](https://baike.baidu.com/item/%E9%98%B3%E8%B7%B7%E8%84%89/7076042)。
* 上行躯干：沿外踝后方、下肢外侧后缘上行，经过腹部、胸部后外侧、肩部和颈部外侧。
* 到达头部：上挟口角，最终到达眼内角（与阴跷脉交会）。 [1, 4, 5]

## 核心生理功能

* 调节阳气：平衡一身的阳气，维持身体的温煦与兴奋。
* 支配运动：主宰下肢肌肉与关节，使双腿行动灵活矫捷。
* 司眼睑开合：濡养眼睛，阳跷脉盛时眼睛睁开、保持清醒（不欲睡）。 [1, 2, 3]

## 常见病理表现

* 阳盛：可见目赤、目痛、失眠或足外翻。
* 气虚或不足：常出现眼睑下垂（嗜睡）、下肢外侧疼痛或畏寒僵硬。 [1, 2]

# 19
阴维脉

阴维脉是中医“奇经八脉”之一，主要功能是维系、联络全身的阴经。 [1, 2]
## 循行路线

* 起穴：起于小腿内侧的[筑宾穴](https://baike.baidu.com/item/%E9%98%B4%E7%BB%B4%E8%84%89/7076123)（足少阴肾经）。
* 上行路径：沿下肢内侧上行至腹部，与足太阴脾经、足厥阴肝经等阴经相会合。
* 终点：上行至咽喉部，并与任脉交会于天突穴和廉泉穴。 [1, 2, 3, 4, 5]

## 生理与病候

* 生理功能：调节和蓄积全身阴经的气血，使阴阳保持平衡。
* 主要病症：阴维脉受损或气血失调时，常见表现为心痛、胸中痛、肋下胀满等症。 [1, 6]

# 20
阳维脉

阳维脉是中医“奇经八脉”之一，“维”有维系、联络的意思，主要功能是维系和联络全身的阳经。 [1, 2]
## 基本概况

* 起点：起于足太阳膀胱经的[金门穴](https://baike.baidu.com/item/%E9%98%B3%E7%BB%B4%E8%84%89/7076162)（在足外踝下方）。
* 循行：向上经过下肢外侧、侧腹、侧胸、肩部、颈部，到达头部与督脉会合。
* 主要作用：联络诸阳经，调节全身气血，具有抵御外邪、维持阴阳平衡的作用。 [2, 3, 4, 5, 6]

## 相关病候

* 常见症状：当阳维脉功能失调时，常会出现畏寒发热（苦寒热）、头晕目眩、肩痛气短（肩息）、神情恍惚（怅然失志）等表现。 [3, 6]
