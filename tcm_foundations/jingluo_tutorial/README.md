# 十二正经与奇经八脉教程

This generated 20-lesson tutorial supplements Chapter 5 of `tcm_foundations`.
Each lesson uses the same study structure: channel pathway, traditional
relationships, a curated major-point list, memory tasks, and a Google lookup.

The point lists are intentionally not treatment prescriptions or exhaustive
lists of every standardized point. The six extraordinary vessels other than
督脉 and 任脉 do not have independent point sequences, so their lessons identify
opening/paired points and representative crossing points.

Images for the twelve regular channels plus 督脉 and 任脉 were supplied as
local course files without embedded source metadata. The other six
extraordinary-vessel charts come from the Wellcome Collection via Wikimedia
Commons under CC BY 4.0; each generated lesson links to its attribution page.

`google_ai_overviews.md` is the user-maintained source for the separately
labelled Google AI Overview sections. The build validates all 20 number/name
pairs before converting its limited Markdown syntax into lesson HTML.

Regenerate the course with:

```bash
python3 practice/tcm_foundations/jingluo_tutorial/build_tutorial.py
```
